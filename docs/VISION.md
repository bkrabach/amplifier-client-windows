# Amplifier for Windows

Direction: user-authorized Windows client, November 16, 2026. This direction is
not evidence of a qualified Windows release.

Amplifier is the application; Tempo is its optional floating companion. Reach
the same host-owned work through the system tray, notifications, quick replies,
and Tempo. The first workspace opens the existing web/PWA application. A future
embedded workspace must preserve the shared client experience and use a narrow,
trusted-origin native bridge. There is no second agent runtime in this client.

Start with the Mac client's established multi-service and companion experience:
six avatars, clear/dark artwork, semantic activity indications, canonical attention,
optional service grouping, stable scroll/resize anchoring, local dismissal, and
visible/hidden/hover notices. Reuse approved artwork; use Windows controls,
credentials, accessibility, notification and installation mechanisms.

Minimize the actions needed to reach a result without overwhelming the interface.
Meaningful authorization and target selection justify an extra action. Passive
hover, scroll, drag and collapse leave keyboard focus with the previous app.
Explicitly opening a chat, composer or settings changes focus deliberately.

Keep registration, commands and presentation scoped to the exact service. Reading
attention in the workspace clears its desktop representation through host facts.
Hiding Tempo does not disconnect or cancel accepted work. Quitting stops this
client's polling. Chat approval gives no local browser or desktop execution rights.

Signed installation, update recovery, real Windows focus and accessibility, and
host compatibility require their own evidence. Mac acceptance is inspiration and
source provenance, not Windows qualification. Public release waits for those gates.

Compatibility decision, November 16: current services must remain usable with
restricted browser-approved chat credentials. A bounded, identity-checked adapter
may bridge the shipped companion feed until the host grants the already-advertised
generic reads to that scope. Generic observations remain the target; neither a
full-control credential nor a server upgrade is a prerequisite for this pilot.
